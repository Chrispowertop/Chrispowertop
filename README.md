# 👋 Sobre mim

Olá! Sou estudante de **Engenharia da Computação na Universidade de Sorocaba (UNISO)**, interessado em tecnologia, desenvolvimento de software, hardware e análise de dados.

Estou sempre aprendendo, explorando novas tecnologias e desenvolvendo projetos para transformar conhecimentos teóricos em soluções práticas.

Gosto de trabalhar na integração entre **software e hardware**, desenvolver aplicações, automatizar processos, manipular dados e explorar sistemas embarcados. Tenho interesse em entender como as tecnologias funcionam desde o nível mais próximo do hardware até aplicações e sistemas de maior complexidade.

Atualmente, venho aprofundando meus conhecimentos em Python, desenvolvimento web, análise de dados, C/C++ e sistemas embarcados, sempre buscando ampliar minha experiência por meio de projetos práticos.

## 🚀 Projetos

Alguns projetos que desenvolvi ou estou desenvolvendo para aplicar e aprofundar meus conhecimentos:

### 🛒 DispensaNet
Sistema voltado ao gerenciamento e acompanhamento de preços de produtos em supermercados, envolvendo desenvolvimento web, integração com banco de dados e análise de informações.

### 📡 DispensaNet RFID
Extensão do projeto DispensaNet utilizando ESP32-S3, leitores RFID e display TFT. Desenvolvido para realizar a identificação de produtos e integrar informações entre hardware e software.

Repositório: [DispensaNet RFID](https://github.com/Chrispowertop/Dispensanet-RFID)

### 🧮 Calculadora em Python
Aplicação desktop desenvolvida em Python utilizando Tkinter, com interface gráfica e operações matemáticas.

Repositório: [Calculadora Python](https://github.com/Chrispowertop/calculadora-python)
